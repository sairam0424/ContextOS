## Overview
Key principles of agent-based systems, focusing on context-driven execution and memory management.

## Patterns
- **Context-driven execution**: Agents reason based on provided context rather than just parameters.
- **Memory-based reasoning**: Using project memory and history to improve future performance.
- **Self-improving loops**: Agents that analyze their own performance to update their memory.

## Best Practices
- Always load minimal context to prevent context window bloat.
- Use structured memory (e.g. `memory.md`) for long-term storage.
- Implement explicit write-back protocols for all agent interactions.

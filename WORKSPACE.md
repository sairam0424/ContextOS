# WORKSPACE.md (MASTER INDEX FILE)

## 🎯 What this Workspace is
This is the **Personal Workspace Context OS**. A file-first, agent-centric architecture designed for high-fidelity context loading and long-term memory for AI agents.

## 📈 Scope Rings
- **Root (Soul & Essence)**: Core identity, philosophy, and global decisions.
- **Org (Contextual Boundaries)**: Personal, work, or other high-level organizational groups.
- **Project (Operational Units)**: Specific goals and products, with detailed operational memory.

## 📁 Directory Overview
- `root/`: Global personality, identity, and decisions.
- `daily/`: Chronological logs and weekly/monthly summaries.
- `orgs/`: High-level organizational context.
- `projects/`: Active operational units for specific goals.
- `skills/`: Reusable agent-ready knowledge modules.
- `knowledge/`: Synthesized learnings, domains, and references.
- `config/`: System-wide settings and templates.

## 📝 Context Loading Rules
1. **Always read** `root/soul.md` and `root/personality.md` at the start of any new session.
2. **Prioritize local project-level context** (`CONTEXT.md`, `memory.md`) within project folders.
3. **Internalize Past Learnings**: Read `AGENTS_LEARNING.md` to prevent repeating past mistakes.
4. **Log status updates** daily in `daily/` using `config/templates/daily-log.md`.

## 🤖 Agent Usage Instructions
- **Read before speaking**: Always check the root context before making architectural assumptions.
- **Record decisions**: Any major deviation from the original plan should be recorded in `root/decisions.md`.
- **Maintain purity**: Do not create non-standard directories outside the defined scaffolding.
